# Source Code

This folder is intended to contain the source code for the Kisan Setu application.

As the project develops, the different parts of the platform will be organised here to make the code easier to understand, maintain and update.

## Planned Structure

The source code is expected to be organised into the following sections:

- **Frontend:** User interface and pages through which farmers interact with the platform.
- **Backend:** Application logic, data processing and communication between different components.
- **AI Agents:** Implementation of the four specialised agents responsible for price monitoring, selling and storage guidance, storage and credit information, and coordination.
- **Database:** Storage and management of farmer profiles, crop details, market information and other relevant records.
- **Utilities:** Common functions and supporting modules used across the application.

## Development Status

The project is currently being developed as a prototype. The structure and contents of this folder will be updated as individual components are implemented and tested.

Only features that have actually been developed and tested will be described as implemented.
